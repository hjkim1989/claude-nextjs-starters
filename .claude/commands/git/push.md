---
description: 변경사항을 분석해 한 줄 요약으로 커밋 후 푸시
model: sonnet
---

아래 순서로 진행해주세요.

1. git status와 git diff로 현재 변경사항을 확인합니다.
2. .env 파일, API 키, 토큰 등 민감한 정보가 포함되어 있으면 커밋하지 말고 중단한 뒤 알려주세요.
3. 변경 내용을 분석해 커밋 메시지를 작성하고 커밋합니다.
   - 한글로, 한 줄(50자 이내)로 작성합니다.
   - 무엇을 바꿨는지가 드러나게 씁니다. 예: "문의 폼 유효성 검사 추가"
   - 본문(상세 설명)은 쓰지 않습니다.
4. 현재 브랜치를 원격 저장소(origin)에 푸시합니다.
5. 푸시가 거절되면 강제 푸시(--force)는 하지 말고, 원인을 한글로 설명한 뒤 해결 방법을 제안해주세요.
6. 완료 후 커밋 메시지와 푸시 결과를 한 줄로 알려주세요.
